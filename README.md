## Quick Start: Checking Pull Requests

This repository includes tools to help you check open pull requests:

### Using the Script

```bash
# Run the convenience script
./check-prs.sh
```

### Using GitHub CLI

```bash
# List open PRs
gh pr list --state open

# Check PR status
gh pr status
```

### Using GitHub Copilot Spaces

Ask Copilot: `check open pull requests`

📚 For more details, see [docs/checking-pull-requests.md](docs/checking-pull-requests.md)
